# Aqua Color Palette Reference

Illustrative, era-inspired colors chosen for these examples; not an official Apple or NeXT palette. Use semantic colors for readable text and accessibility.

| Element | Hex / RGB | Description |
| :--- | :--- | :--- |
| **Aqua Blue (Top)** | `#58b0f6` | Specular upper curve of active jelly button |
| **Aqua Blue (Mid)** | `#1c7ad6` | Core vibrant body color |
| **Aqua Blue (Bottom)** | `#0a4c9c` | Deep bottom gradient shade |
| **Graphite (Top)** | `#9c9ea2` | Pro audio / video application accent |
| **Graphite (Bottom)** | `#525458` | Dark neutral bottom shade |
| **Candy Blue Stripe** | `#0084ff` | High-contrast animated progress stripe |
| **Candy Cyan Stripe** | `#00d0ff` | Light animated progress stripe |
| **Pinstripe White** | `#fefefe` | Alternating vertical background stripe |
| **Pinstripe Gray** | `#ececec` | Alternating vertical background stripe |
| **Brushed Metal High** | `#d0d0d0` | Top aluminum reflection |
| **Brushed Metal Low** | `#a8a8a8` | Bottom aluminum base |
| **Etched Text Shadow** | `#ffffff` (alpha 0.7) | `x: 0, y: 1` shadow beneath dark text |
