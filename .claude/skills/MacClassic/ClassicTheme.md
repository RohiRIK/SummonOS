# Classic Platinum Color Palette Reference

Illustrative, era-inspired colors chosen for these examples; not an official Apple or NeXT palette. Use semantic colors for readable text and accessibility.

| Element | Hex / RGB | Description |
| :--- | :--- | :--- |
| **Platinum Body Gray** | `#d8d8d8` / `RGB(216, 216, 216)` | Signature Mac OS 8/9 window and control background |
| **System White Highlight** | `#ffffff` / `RGB(255, 255, 255)` | Top and left 3D light reflection |
| **Mid Shadow Gray** | `#808080` / `RGB(128, 128, 128)` | Inset and bottom-right 3D bevel shade |
| **Pinstripe & Border Black** | `#000000` / `RGB(0, 0, 0)` | 1px crisp window strokes and 6-line stripes |
| **System 7 Desktop Dither** | Alternating `#808080` / `#ffffff` | 50% 1-bit checkerboard desktop pattern |
| **Charcoal Dark Gray** | `#333333` / `RGB(51, 51, 51)` | Inactive title text and disabled controls |
| **Classic Accent Blue** | `#333399` / `RGB(51, 51, 153)` | Selection highlight in Mac OS 8/9 Appearance Control Panel |
| **Classic Accent Apple Red**| `#cc0000` / `RGB(204, 0, 0)` | Classic warning / alert badge color |
