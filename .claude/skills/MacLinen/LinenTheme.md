# MacLinen Color Palette Reference

Illustrative, era-inspired colors chosen for these examples; not an official Apple or NeXT palette. Use semantic colors for readable text and accessibility.

| Element | Hex / RGB | Description |
| :--- | :--- | :--- |
| **Dark Linen Base** | `#2b2b2b` / `RGB(43, 43, 43)` | Woven cross-hatch fabric background |
| **Linen Highlight** | `#ffffff` (alpha 0.08) | Subtle fabric fiber reflection |
| **Saddle Leather Top** | `#6b3824` / `RGB(107, 56, 36)` | Rich calfskin upper gradient |
| **Saddle Leather Bottom** | `#472414` / `RGB(71, 36, 20)` | Deep embossed leather shade |
| **Stitch Line White** | `#e6e6e6` (alpha 0.65) | Contrasting dashed thread stitch |
| **Legal Pad Yellow** | `#fdf6c7` / `RGB(253, 246, 199)` | Notes stationery background |
| **Legal Pad Margin Red**| `#eb7373` / `RGB(235, 115, 115)` | Vertical left margin rule |
| **Legal Pad Ruled Blue** | `#a6c7e6` / `RGB(166, 199, 230)` | Horizontal ruled handwriting guide lines |
| **Bead-Blasted Aluminum**| `#e0e0e0` / `RGB(224, 224, 224)` | Unified toolbar aluminum texture |
