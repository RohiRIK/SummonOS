# Yosemite Color Palette Reference

Illustrative, era-inspired colors chosen for these examples; not an official Apple or NeXT palette. Use semantic colors for readable text and accessibility.

| Element | Hex / RGB | Description |
| :--- | :--- | :--- |
| **System Blue Accent** | `#007aff` / `RGB(0, 122, 255)` | Pure vibrant flat primary action blue |
| **Frosted Sidebar Light** | Translucent vibrancy | Blurs desktop behind window with slight cool tint |
| **Window Content White** | `#f6f6f6` / `RGB(246, 246, 246)` | Flat matte content pane background |
| **Mojave Dark Surface** | `#262626` / `RGB(38, 38, 38)` | 10.14 dark mode window background |
| **Control Border Gray** | `#d0d0d0` / `RGB(208, 208, 208)` | 1px flat control stroke |
| **Active Green Pill** | `#34c759` / `RGB(52, 199, 89)` | Green indicator badge |
| **Active Orange Pill** | `#ff9500` / `RGB(255, 149, 0)` | Warning / alert flat pill |
